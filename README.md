# Задание 1

## Задача 3

### Текст задачи

Создайте сущность Имя, которая описывается тремя параметрами: Фамилия, Личное имя, Отчество. Имя может быть приведено к строковому виду, включающему традиционное представление всех трех параметров: Фамилия Имя Отчество (например "Иванов Иван Иванович"). Необходимо предусмотреть возможность того, что какой-либо из параметров может быть не задан, и в этом случае он не учитывается при приведении к текстовому виду. Необходимо создать следующие имена: Клеопатра, Пушкин Александр Сергеевич, Маяковский Владимир.

### Алгоритм решения

Создан класс `Name`, содержащий три строковых поля. Если какой-то параметр не задан, строка остается пустой. Реализованы три конструктора для создания имени с одним, двумя или тремя параметрами. Метод `print()` выводит строку в формате "Фамилия Имя Отчество", проверяя с помощью метода `empty()` наличие каждого поля, чтобы избежать лишних пробелов.

# Задание 2

## Задача 2, 3

### Текст задачи

Объедините сущности Человек и Имя таким образом, чтобы имя человека задавалось с использованием сущности из задачи 1.3. Измените сущность Человек, добавив ему возможность задавать третий параметр: Отец, где Отец — это тоже Человек. При приведении человека к строковой форме необходимо проверить параметры имени: если нет фамилии и есть отец с фамилией, фамилия заимствуется; если нет отчества, а у отца есть имя, задается отчество как имя отца с суффиксом “ович”. Создать людей: Чудова Ивана, Чудова Петра, Бориса. Сделать Ивана отцом Петра, а Петра отцом Бориса.

### Алгоритм решения

Класс `Person` использует композицию (содержит объект `Name`) и агрегацию (хранит указатель на отца `const Person*`). В конструкторах, принимающих указатель на отца, вызывается вспомогательный метод `ResolveFatherInfo()`. Этот метод проверяет наличие фамилии и отчества у текущего человека. Если фамилия пуста, она копируется у отца. Для отчества вызывается метод `MakePatronymic()`, который добавляет суффикс "ович" или "евич" (в зависимости от окончания имени отца, с учетом словаря исключений, например, для имен Павел, Лев, Петр).

# Задание 3

## Задача 3

### Текст задачи

Создайте сущность Город, которая будет представлять собой точку на карте со следующими характеристиками: Название города, Набор путей к следующим городам, где путь представляет собой сочетание Города и стоимости поездки в него. Город может возвращать текстовое представление в виде названия города и списка связанных с ним городов. Используя разработанную сущность реализуйте схему.

### Алгоритм решения

Класс `City` хранит название и вектор путей, реализованный через `std::vector<std::pair<City*, int>>`, где `first` — указатель на город назначения, а `second` — стоимость. Метод `add_path()` добавляет новую связь. Метод `print()` перебирает вектор путей и выводит названия городов и стоимость поездки в формате "название:стоимость". В функции демонстрации вручную создаются объекты и связи между ними строго по схеме из задания.

# Задание 4

## Задача 5, 6

### Текст задачи

5. Измените сущность Имя. Имя можно создать указав только Личное имя; Личное имя и Фамилию; или все три параметра. 
6. Измените сущность Человек. Человека можно создать с указанием имени в виде строки (считается заданным только имя); с указанием имени в виде строки, роста и отца (отчество проставляется автоматически); с указанием имени в виде объекта типа Имя и роста; с указанием имени в виде объекта, роста и отца (проверяется наличие отчества и фамилии, при необходимости они задаются).

### Алгоритм решения

В классе `Name` добавлены конструкторы для различных комбинаций параметров, при этом для конструктора с одним аргументом использовано ключевое слово `explicit` во избежание неявного преобразования строк в объекты. В классе `Person` реализованы все четыре требуемые перегрузки конструктора, комбинирующие передачу строки/объекта `Name` и наличие/отсутствие указателя на отца. Вся логика работы с отцом инкапсулирована в конструкторах и методе `ResolveFatherInfo()`.

# Задание 5

## Задача 2

### Текст задачи

Создайте сущность Кот, которая описывается: Имя (строка). Для создания необходимо указать имя кота. Может быть приведен к текстовой форме вида: "кот: Имя". Может помяукать, что приводит к выводу "Имя: мяу!". Может помяукать N раз, что приводит к выводу "Имя: мяу-мяу-...-мяу!". Создайте кота по имени "Барсик", и затем пусть он помяукает сначала один раз, а затем три раза.

### Алгоритм решения

Создан класс `Cat`, единственным полем которого является строка с именем. Для реализации мяуканья использована перегрузка методов: `meow()` без параметров выводит одиночное "мяу!", а `meow(int count)` в цикле формирует строку с "мяу", разделенными дефисами, не добавляя дефис после последнего элемента.
